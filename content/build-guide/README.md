# Building Guide content

One JSON file per page. Edit the text here — no code changes needed.

- File names start with a number (`01-`, `02-` …) that sets the order; `slug` is the web address (`/build-guide/<slug>`).
- `kind`: `"stage"` for construction stages, `"guide"` for the "Managing your build from abroad" page.
- Lists (`whatHappens`, `problems`, `questions`, `photoCheckpoints`) are shown as bullet points in that order.
- `[CHECK]` marks text that a QS/engineer should confirm before publishing; it is shown on the page as a small "to be confirmed" tag.
- Keep JSON valid: text inside double quotes, items separated by commas. No prices in Phase 1.
